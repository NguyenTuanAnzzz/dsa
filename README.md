# DSA mỗi ngày

**Mỗi ngày một thuật toán, mỗi ngày một bài LeetCode.**

Xem web: **https://dsa-nine-rho.vercel.app**

Lộ trình 40 ngày qua 8 dạng thuật toán cơ bản. Mỗi ngày học một thuật toán: đọc lý thuyết, xem nó chạy từng bước, đọc code Java, rồi làm một bài LeetCode dùng đúng thuật toán đó.

## Mỗi ngày có gì

- **Lý thuyết**: thuật toán làm gì và vì sao nó chạy đúng.
- **Cách hoạt động**: các bước đánh số.
- **Mô phỏng từng bước**: bấm qua từng bước như debugger, hoặc để tự chạy. Có ở 13 thuật toán sắp xếp và tìm kiếm.
- **Code Java**: tô màu cú pháp, có số dòng, có nút chép.
- **Độ phức tạp**: tốt nhất, trung bình, xấu nhất, bộ nhớ. Kèm biểu đồ so sánh với các lớp O(1) đến O(n²).
- **Bài LeetCode hôm nay**: lời giải được ẩn sẵn để bạn tự làm trước.
- **Luyện thêm**: 2 đến 3 bài cùng dạng. Tổng cộng 127 bài LeetCode khác nhau.

## Trang chủ

Trang chủ làm theo kiểu bảng điều khiển trạm vệ tinh:

- **Trạm DSA 3D** (Three.js): mỗi khối là một ngày học. Mỗi cụm có hình giống cấu trúc dữ liệu của dạng đó: mảng cho sắp xếp, lưới cho quy hoạch động, mạng nút cho đồ thị, cây nhị phân cho cây. Kéo để xoay, bấm vào khối để mở ngày học.
- **Tiến độ**: chia theo độ khó Easy, Medium, Hard.
- **Hoạt động 14 ngày gần nhất** và **nhật ký** những ngày đã học.
- **Danh sách nhiệm vụ**: đủ 40 ngày, lọc theo dạng, đánh dấu đã học ngay trong bảng.
- **Tìm nhanh**: bấm `Ctrl K` để tìm theo tên thuật toán hoặc số bài LeetCode.

Tiến độ được lưu trong `localStorage` của trình duyệt. Không cần tài khoản, không có server, dữ liệu không rời khỏi máy bạn. Đổi máy hoặc xóa dữ liệu trình duyệt thì tiến độ bắt đầu lại.

## Công nghệ

- [Vite](https://vite.dev) + [React 18](https://react.dev)
- [Three.js](https://threejs.org) cho mô hình 3D. Gói này chỉ tải khi mở trang chủ, nên trang thuật toán không bị nặng thêm.
- CSS thuần, không dùng UI framework. Biểu đồ vẽ bằng SVG.
- Font: Chakra Petch và JetBrains Mono (Google Fonts), cả hai đều có dấu tiếng Việt.

## Chạy trên máy

Cần Node.js 18 trở lên.

```bash
git clone https://github.com/NguyenTuanAnzzz/dsa.git
cd dsa
npm install
npm run dev
```

Mở địa chỉ Vite in ra, mặc định là `http://localhost:5173`.

Build bản production:

```bash
npm run build
npm run preview
```

Kết quả build nằm trong `dist/`.

## Cấu trúc thư mục

```
src/
  data/
    sorting.js, searching.js, dp.js, graph.js, others.js   nội dung từng thuật toán
    index.js                                               gom dữ liệu, đánh số ngày
  viz/steps.js        sinh các bước mô phỏng cho sắp xếp và tìm kiếm
  components/
    StationScene.jsx  trạm DSA 3D (Three.js)
    Home.jsx          bảng điều khiển ở trang chủ
    AlgoPage.jsx      trang của một ngày học
    Visualizer.jsx    mô phỏng từng bước
    Charts.jsx        biểu đồ hoạt động và độ phức tạp
    QuickOpen.jsx     tìm nhanh Ctrl K
    CodeBlock.jsx     khối code Java
  lib/
    progress.js       tiến độ, nhật ký, định tuyến bằng hash
    highlight.js      tô màu cú pháp Java
```

## Thêm một ngày mới

1. Thêm một object vào file của dạng tương ứng trong `src/data/`. Dùng một mục có sẵn làm mẫu: `slug`, `name`, `category`, `theory`, `steps`, `complexity`, `insight`, `code`, `problems`, `solution`.
2. Số ngày được đánh tự động theo thứ tự trong `src/data/index.js`.
3. Muốn có mô phỏng từng bước: thêm trường `viz` và viết hàm sinh bước trong `src/viz/steps.js`.
4. Muốn khối mới hiện trong mô hình 3D: nếu là dạng mới thì thêm cấu hình cụm trong `CLUSTERS` ở `StationScene.jsx`.

## Deploy

Web đang chạy trên Vercel. Mỗi lần push lên nhánh `main`, Vercel tự build và deploy lại.

Cài đặt trên Vercel: Framework Vite, Build Command `npm run build`, Output Directory `dist`, không cần biến môi trường. Web dùng hash routing (`#/algo/quick-sort`) nên không cần cấu hình rewrite.
